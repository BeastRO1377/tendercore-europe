# Pre-publication checklist

- [x] Public distribution scope separated from ProjectControl source.
- [x] Apache-2.0 license and basic contribution/security policies included.
- [x] No `.env`, personal SQLite, cache or local report included in packaging.
- [x] Offline Python tests run.
- [x] Screenshots regenerated from synthetic examples with live in-process API responses and no browser errors.
- [ ] End-to-end TED Search API and representative eForms XML tested from a live network.
- [ ] Real-world eForms/lot mapping manually validated against official TED notices.
- [ ] Third-party dependency-license and supply-chain audit completed.
- [ ] Privacy/security review completed before any remote hosting.
- [ ] Final public repository, branch protections and private vulnerability reporting configured.
- [ ] Release tag and first GitHub Release published.

Alpha may be published transparently with the unchecked limits disclosed; do not claim production readiness.
